🪑 AI-Powered Library Seat Monitoring System : 

Overview : 
💬 Product Summary
1. The AI-Powered Library Seat Monitoring System is a computer vision-based solution that automatically detects empty and occupied seats in a library or study space using a single camera feed.
2. It also identifies whether seated individuals are actively studying or slacking off, and sends gentle reminders when inactivity or distraction is detected.

💬 Goal
1. Automate seat occupancy tracking.
2. Improve resource utilization in shared spaces (like libraries or coworking zones).
3. Encourage focus and productivity through posture and engagement feedback.

Problem Statement : 
1. Manual monitoring of seat occupancy and student engagement in libraries is inefficient.
2. Staff cannot continuously track which seats are available or who’s distracted.
3. This leads to wasted space and reduced study efficiency.

Proposed Solution : 
1. An AI system using OpenCV and YOLOv8 will:
2. Detect chairs and persons in real-time video streams.
3. Associate each person with their chair to determine seat occupancy.
4. Monitor posture and activity to detect slacking (e.g., head down, looking away, phone usage).
5. Provide real-time visual overlays, logs, and optional reminder alerts.

Key Features : 
💬 Feature	Description
🪑 Automatic Seat Detection	: Detect and map all chairs dynamically — no manual region labeling required.
🧍‍♂️ Occupancy Detection : Identify if a chair is empty or occupied using bounding box overlap between chair and person detections.
🧠 Posture Analysis : Analyze upper body position and movement to identify focused vs slacking posture.
🔔 Smart Reminders : Send visual/sound notifications if user remains inactive or distracted for a defined duration.
📊 Dashboard / Logs : Store and display real-time analytics (seat utilization %, focus time, occupancy duration).

Architecture / Pipeline : 

[Video Feed / Camera Input]
            ↓
[YOLOv8n Detects Chairs + Persons]
            ↓
[Assign Seat IDs + Check Person-Chair Overlap]
            ↓
[Determine Occupancy Status (Empty / Occupied)]
            ↓
[Posture Analysis + Slack Detection]
           ↓
[Output Overlay + Logs + Alerts / Dashboard]

Technical Implementation : 

💬 Detection Module (YOLOv8n):
1. Classes: chair, person.
2. Outputs bounding boxes + confidence scores per frame.

💬 Seat-Person Association:
1. Overlap IoU-based assignment.
2. If a person overlaps a chair → seat = occupied.
3. If not → seat = empty.

💬 Posture & Activity Tracking:
1. Use Mediapipe Pose or lightweight posture classifier.
2. Measure head/shoulder tilt, phone-hand movement, or inactivity over time.

💬 Alert System:
3. Trigger reminder (sound/notification) if slacking detected for >30 sec.
4. Store alert timestamp in logs.

💬 Visualization:
1. Overlay bounding boxes (🟩 empty / 🟥 occupied / 🟨 distracted).
2. Display seat count and occupancy percentage.
